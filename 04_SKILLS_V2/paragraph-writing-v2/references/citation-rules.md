# Citation and reference rules

## Principles
- Cite only SOURCES recorded in Step 1.
- Name, year, and page come exactly from the PDF. Never complete them from memory.
- Every sentence reporting source content carries a citation with a page.
- Interpretation sentences carry no page citation.
- Base style: APA 7 adapted to Indonesian ("dan", "dkk.", "hlm."). If the user
  names an institutional or journal guide, it overrides these rules.

## In-text format
| Authors | Parenthetical | Narrative |
|---|---|---|
| One | (Rahman, 2024, hlm. 8) | Rahman (2024, hlm. 8) melaporkan bahwa ... |
| Two | (Rahman dan Sari, 2024, hlm. 8) | Rahman dan Sari (2024, hlm. 8) menemukan ... |
| Three or more | (Rahman dkk., 2024, hlm. 8) | Rahman dkk. (2024, hlm. 8) menunjukkan ... |
| Organization | (Kementerian Kesehatan, 2023, hlm. 12) | Kementerian Kesehatan (2023, hlm. 12) ... |

- The sentence period goes after the closing parenthesis.
- Pages: hlm. 8; range hlm. 8–9; separate pages hlm. 8, 12.
- Table or figure values: (Rahman dkk., 2024, hlm. 8, Tabel 3).
- Use the page numbering fixed in Step 1 (printed number; if none, PDF index,
  and say so in the output note).
- Same surname and year for different authors: add initials. Same author and
  year for two works: 2024a, 2024b.

## Direct quotes
Prefer full paraphrase. At most one quote per source, under 15 words, in
quotation marks with page. Foreign terms in italics.

## Secondary citations
Used when an uploaded SOURCE (Author B) reports a finding from a work that was
not uploaded (Author A).
- Form: (Penulis A, Tahun, dikutip dalam Penulis B, Tahun, hlm. X).
- Take A's name and year only from B's text or reference list. If A's year is
  uncertain, cite B alone and state that B refers to another work.
- Use A's numbers only if B prints them.
- The reference list contains B only.
- If an uploaded SOURCE reports the same finding directly, cite that SOURCE instead.

## Multiple sources
- Alphabetical by first author, separated by semicolons, page for each:
  (Putra dan Dewi, 2023, hlm. 4; Rahman dkk., 2024, hlm. 8).
- Use only when each source passes verification and supports the same claim.
- Duplicate or mutually citing sources count as one line of evidence.
- Conflicting results go in separate sentences, not one parenthesis.

## Incomplete data
- Author or year missing: the source cannot be cited in text. Tell the user which
  field is missing and ask for it. Do not guess and do not use "t.t." unless printed.
- Page uncertain: the evidence is Dropped.
- Only a reference-list field missing (DOI, volume): the sentence may stay; write
  "[tidak tercantum dalam PDF]" in the reference list.

## Reference list
Only sources cited in the paragraph, alphabetical, APA 7 with Indonesian punctuation.
Journal name and volume in italics.

Journal article:
Rahman, A., Sari, D., & Putra, B. (2024). Article title in sentence case. Journal Name, 12(3), 45–60. https://doi.org/xxxx

Proceedings:
Rahman, A. (2024). Paper title. Dalam B. Putra (Ed.), Proceedings title (hlm. 101–110). Publisher.

Preprint:
Rahman, A., & Sari, D. (2024). Preprint title. arXiv. https://arxiv.org/abs/xxxx

Thesis:
Rahman, A. (2023). Thesis title [Tesis magister, University name]. Repository.

Institutional report:
Kementerian Kesehatan. (2023). Report title. Publisher.

Rules: only fields printed in the PDF; never invent a DOI; the list must match
the in-text citations exactly; STYLE REFERENCE files never appear.

## Common errors
| Wrong | Right |
|---|---|
| (Rahman et al., 2024) | (Rahman dkk., 2024, hlm. 8) |
| (Rahman dkk, 2024) | (Rahman dkk., 2024, hlm. 8) |
| (Rahman & Sari, 2024) in text | (Rahman dan Sari, 2024, hlm. 8) |
| ... set uji. (Rahman dkk., 2024) | ... set uji (Rahman dkk., 2024, hlm. 8). |
| No page on a sentence with numbers | Add hlm. and Tabel or Gambar |
| Citing Author A as if read | (Penulis A, Tahun, dikutip dalam Penulis B, Tahun, hlm. X) |
| Guessed year or initials | Ask the user |
| Citation on an interpretation sentence | Remove the citation |
| hal. or h. | hlm. |
